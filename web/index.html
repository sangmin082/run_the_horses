Run the Horses · 웹 프로토타입
1라운드
게임 규칙
  • 말을 정중앙 오아시스에 먼저 도착시키면 라운드 승리. 3판 2선승.
  • 슬라이드 이동(●): 가장자리나 다른 말에 막히기 직전까지 가로/세로로 미끄러진다. 중간에 멈출 수 없다.
  • L자 이동(◆): 체스 나이트처럼 점프. 도착 칸이 비어있는 사막 칸일 때만 가능 — 초원·오아시스에는 L자로 들어갈 수 없다.
  • 오아시스에는 슬라이드로만 도착할 수 있다. 오아시스 반대편 인접 칸에 말(블로커)이 있어야 정확히 멈춘다.
  • 라운드마다 선공이 바뀐다 (1·3라운드: 밤색 말, 2라운드: 흰 말).

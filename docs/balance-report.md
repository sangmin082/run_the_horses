# 밸런스 리포트 — 선공 승률 시뮬레이션 (1차)

플랜 §4의 "엔진 기반 검증" 1차 실험 결과. `node tools/simulate.js <게임수> <깊이> <시드>`로 재현 가능.

## 설정
- 단일 라운드, 선공 고정(P1), 라운드 교대 없음 — 순수 선공 우위 측정 목적
- AI: 네가맥스 + 알파-베타, 루트에서 상위 2~4개 수 중 무작위 선택(기보 다양화)
- 수 제한 200플라이 초과 시 무승부 처리

## 해석

1. **얕은 탐색(깊이 2~4) + 무작위성 조건에서는 압도적 선공 우위가 관측되지 않는다.**
   원작에 알려진 "선공 필승법"은 완전한 수읽기를 전제로 한 것으로 보이며, 현재 AI의
   탐색 깊이로는 필승 라인을 안정적으로 찾지 못한다. 즉 **캐주얼~중수 레벨의 실제 플레이
   경험에서는 밸런스 문제가 크지 않을 가능성**이 높다.
2. 무승부(교착)가 0%로, 수 제한 내에 항상 승부가 났다. 평가 함수가 중앙 접근을
   보상하기 때문에 게임이 앞으로 진행되는 구조다.
3. 깊이 4는 Node 기준 수당 ~0.6초로, 모바일 웹에서는 체감이 느리다. 하드 난이도는
   깊이 3으로 설정했다 (깊이 4는 네이티브 빌드/백그라운드 isolate에서 재도입 예정).

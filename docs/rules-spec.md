# 말 달리자 — 규칙 명세 (v1.0)

구현 기준 명세. `engine/src/`가 이 명세의 레퍼런스 구현이며, Flutter/네이티브 포팅 시
이 문서와 엔진 단위 테스트(`engine/test/`)를 기준으로 검증한다.

## 1. 보드

- 11×11 격자. 좌표 표기: 행 `a`~`k`(위→아래), 열 `1`~`11`(왼쪽→오른쪽). 예: `f6` = 정중앙.
- 내부 표현: `idx = r * 11 + c` (r, c ∈ 0..10). 중앙 `CENTER = 60`.
- 칸 종류:
  | 종류 | 정의 | 개수 |
  |------|------|------|
  | 오아시스 | 정중앙 1칸 (`f6`) | 1 |
  | 초원 | 중앙에서 맨해튼 거리 ≤ 2 (오아시스 제외) | 12 |
  | 사막 | 나머지 | 108 |
- 초원 12칸: `d6, e5, e6, e7, f4, f5, f7, f8, g5, g6, g7, h6`

## 2. 말과 초기 배치

- 각 플레이어 말 10개. 말이 제거되는 규칙은 없다(캡처 없음).
- 배치: 대각 방향으로 마주보는 두 코너에 ㄱ자(브래킷) 형태로 5개씩.
  - **P1(선공)**: `a1 a2 a3 b1 c1` (좌상) + `i11 j11 k11 k10 k9` (우하)
  - **P2(후공)**: `a9 a10 a11 b11 c11` (우상) + `i1 j1 k1 k2 k3` (좌하)
- 출처: 팬게임 horse-run-game 소스와 교차 검증. 원작 영상 대조로 최종 확정 예정.

## 3. 이동

자기 차례에 자신의 말 1개를 아래 두 방법 중 하나로 이동한다. 이동하지 않고
차례를 넘길 수 없다(패스 불가).

### 3.1 슬라이드
- 가로 또는 세로 한 방향으로, **보드 가장자리나 다른 말(자·타 불문)에 막히기
  직전 칸까지** 직선 이동한다.
- 중간에 자의로 멈출 수 없다. 이동 거리가 0이면(바로 옆이 막힘) 그 방향으로는
  이동 불가.
- 도착 칸 종류 제한 없음 (사막·초원·오아시스 모두 가능).

### 3.2 L자 이동
- 체스 나이트와 동일한 8방향 점프: 변위 (±1,±2), (±2,±1).
- 중간 경로의 말은 무시한다(점프).
- **도착 칸이 비어있는 사막 칸일 때만** 가능. 초원·오아시스에는 L자로 도착 불가.

## 4. 승리

- 자신의 말이 **오아시스 칸에 도착하는 즉시** 해당 라운드 승리.
- 따름정리: 오아시스 진입은 슬라이드로만 가능하며, 이동 방향 기준 오아시스
  **반대편 인접 칸에 말(블로커, 소유 불문)이 있어야** 정확히 멈춘다.

## 5. 매치 형식

- 3라운드제, **2라운드 선취** 시 매치 승리.
- 라운드마다 보드를 초기화하고 **선공을 교대**한다: 1·3라운드 P1 선공, 2라운드 P2 선공.

## 6. 선택 규칙 (제품 옵션)

- **파이 룰**: 선공의 첫 수 이후, 후공이 진영 교체를 선택할 수 있다.
  밸런스 실험 결과 검증 배치에서는 자연 균형(선공 46.7%)이라 필수는 아니며
  옵션으로 제공한다. (`docs/balance-report.md`)

## 7. 종료 불능 상태

- 이동 가능한 수가 없는 경우는 실전에서 사실상 불가능하지만, 엔진은 이를
  무승부(0점)로 평가한다. 제품에서는 N수 무진행 시 무승부 규칙(예: 100수) 도입을
  권장한다 (온라인 대전 필수).

## 2. 프로모션 텍스트 (170자)

> 사막 한가운데 단 하나의 오아시스. 미끄러지는 슬라이드와 도약하는 L자 행마로 중앙 라인을 선점하라. AI와의 두뇌 대결부터 방 코드 하나로 시작하는 친구와의 실시간 승부까지 — 먼저 도착하는 말이 승리한다.

## 3. 설명

> 🐎 11×11 사막, 말 10개, 그리고 정중앙의 오아시스.
>
> 「말달리자」는 화제의 1:1 추상전략 대결을 모바일로 옮긴 보드게임입니다.
>
> ◆ 게임 방법
> • 슬라이드 — 말은 가장자리나 다른 말에 막히기 직전까지 가로·세로로 미끄러집니다. 중간에 멈출 수 없습니다.
> • L자 이동 — 체스의 나이트처럼 점프하되, 비어있는 사막 칸에만 도착할 수 있습니다.
> • 오아시스 진입 — 오아시스에는 슬라이드로만 도착할 수 있습니다. 반대편에 말(블로커)이 있어야 정확히 멈춥니다.
> • 단판 승부 — 먼저 오아시스에 도착하면 그대로 승리! 선공은 무작위로 정해집니다.
>
> ◆ 게임 모드
> • 혼자 하기 — 4단계 난이도의 AI와 대결 (전문가 AI는 깊이 9까지 수읽기)
> • 둘이 하기 — 방 코드 하나로 친구와 실시간 온라인 대전
> • 튜토리얼 — 3단계 인터랙티브 학습으로 행마법을 익히세요
> • 퍼즐 — "N수 안에 오아시스 도착" 12문제
>
> ◆ 특징
> • 회원가입 없음, 광고 없음, 인앱 결제 없음
> • 무르기 지원 (혼자 하기)
> • 난이도별 전적 기록

## 5. 심사 메모 (App Review Notes)

> 이 앱은 추상전략 보드게임입니다. 로그인이 필요 없으며 모든 기능을 즉시 사용할 수 있습니다.
> "둘이 하기"는 익명 방 코드 기반 실시간 대전으로, 계정·채팅·개인정보 수집이 없습니다.
> 두 대의 기기로 테스트하시려면: 한 기기에서 방을 만들어 코드를 받고, 다른 기기에서 코드를 입력하면 됩니다.

## 7. 스크린샷 촬영 가이드

**필수 크기는 6.9형(iPhone 17 Pro Max급) 1벌**이며, 다른 크기는 자동 축소 적용된다.

촬영 방법 (Mac):
1. Xcode에서 `RunHorses.xcodeproj` 열기 → 시뮬레이터 대상 **iPhone 17 Pro Max** 선택 → 실행
2. 각 장면에서 시뮬레이터 메뉴 **File → Save Screen** (⌘S) — 정확한 해상도 PNG가 데스크탑에 저장됨
3. App Store Connect 업로드 시 그대로 사용 가능

찍을 장면 5가지 (순서 = 스토어 노출 순서):
- [ ] **대국 중반** — 말을 선택해 이동 힌트(●/◆)가 보이는 장면 (가장 매력적인 첫 장)
- [ ] **승리 오버레이** — 오아시스 도착 직후
- [ ] **홈 화면**
- [ ] **튜토리얼 1단계**
- [ ] **퍼즐 목록** (몇 개 풀어서 체크 표시가 있으면 더 좋음)

## 8. 심사 제출 클릭 경로 (최종)

App Store Connect → 나의 앱 → 말달리자:

1. **일반 → 앱 정보**: 부제(§1), 카테고리 게임/보드(보조: 전략), 콘텐츠 권한 확인
2. **일반 → 연령 등급**: 설문 전부 "없음" → 4+
3. **일반 → 앱 개인정보 보호**: 개인정보 처리방침 URL 입력 → "데이터 수집 안 함" 선택
4. **배포 → 가격 및 판매 가능 여부**: 무료, 모든 국가(또는 원하는 국가)
5. **iOS 앱 1.0 페이지**:
   - 스크린샷 5장 업로드 (§7)
   - 프로모션 텍스트(§2), 설명(§3), 키워드(§4), 지원 URL, 저작권 입력
   - **빌드 선택**: TestFlight에 올라간 최신 빌드
   - App Review 정보: 심사 메모(§5) 붙여넣기, 연락처 입력, 로그인 정보 "필요 없음"
   - 버전 출시 방식: "심사 통과 후 자동 출시" (권장)
6. **심사를 위해 제출** 클릭

심사는 보통 24~48시간. 리젝 시 사유 전문을 Claude에게 전달하면 대응한다.
